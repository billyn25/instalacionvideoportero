# Fotos de trabajos reales

Sube las fotos a `antenas/` o `porteros/` según el servicio. Nombra el archivo con el municipio y un número. Ejemplos: `antenas/bonar-01.jpg` y `porteros/bilbao-01.jpg`.

Para cada intervención, indica municipio, servicio y qué se reparó o instaló. Si hay varias fotos, indica qué archivos son del mismo trabajo. Evita nombres de clientes, números de portal y otros datos que identifiquen el domicilio.

En `data/trabajos.json` se registran las fichas. Cada una requiere un municipio confirmado, el tipo (`antenas` o `porteros`), título, descripción, nombre del archivo y texto alternativo. Los destinos de cobertura y los trabajos documentados se muestran por separado.
