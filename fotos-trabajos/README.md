# Fotos de trabajos reales

Sube aquí las fotos originales de tus trabajos de porteros y videoporteros. Puedes subir una o varias fotos por intervención y nombrarlas con el municipio y un número. Ejemplo: `bilbao-01.jpg` y `bilbao-02.jpg`.

Para cada intervención, indica qué se reparó o instaló, el municipio y qué fotos corresponden. Evita nombres de clientes, números de portal y otros datos que identifiquen el domicilio.

Hay nueve huecos preparados en `data/trabajos.json`. Los nombres son propuestas para organizar el material. Corrige la localidad si las fotos son de otro pueblo. Una ficha se publica cuando tiene título, descripción, texto alternativo y una foto que existe en esta carpeta.
